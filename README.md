# geoscience_data_analysis
A data analysis course with applications to geosciences

This is a course designed for Earth Sciences Honours and Master's students at the University of Adelaide.  The data analysis techniques are applicable to a wide range of backgrounds and diverse geoscientific fields.  None of the techniques used are specific to geoscientific data, but the examples and exercises are generally applied to geoscience data to make the examples directly relevant to many of the students.

The examples are woven into a set of notes using Matlab Live Scripts (mlx-files) that allow the reader to alter and run the code.

To get started, clone (download) the repository.
